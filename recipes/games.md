# Browser games

## Goal

Route game-development work to the authoritative AI instructions instead of duplicating a game framework handbook here.

## Kakkoi School standard

For new browser games, use **LittleJS**.

The authoritative AI game-development repository is:

https://github.com/KilledByAPixel/LittleJS-AI

Before writing game code:

1. read its README.md;
2. read its AGENTS.md;
3. use the relevant LittleJS-AI skill/template/helper;
4. use its exact API reference when unsure rather than guessing.

Do not copy its instructions into this repository. Upstream is the source of truth.

## Existing games

If a project already uses another engine or framework, preserve it unless the student explicitly asks to migrate.

## Multiplayer

If the game needs multiplayer, keep LittleJS as the game engine and additionally follow [multiplayer.md](multiplayer.md) for Kakkoi's p2p-core.

## Verify

Run the game, verify the requested controls/core loop, and check the browser console before claiming success.
