# Recipes

Every recipe uses the same shape:

1. **Goal** — what the student is trying to accomplish.
2. **Before you start** — information and permissions required.
3. **Preferred path** — normally a native GitHub tool or `gh`.
4. **Fallback** — `git`, browser, or Playwright when the preferred path is unavailable.
5. **Verify** — a concrete check that proves the result.
6. **Do not** — common AI mistakes to avoid.

If you are an AI agent, do not merge several recipes into a novel workflow unless the student's request actually requires several operations.
