# GitHub Education and Copilot Student

## Goal

Help eligible students apply for GitHub Education and activate the student Copilot benefit.

Official GitHub Education application guide:
https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student

Official Copilot Student activation guide:
https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students

## Who may qualify

GitHub currently says student applicants must:

- be enrolled in a degree- or diploma-granting program such as a high school, college, university, or homeschool;
- provide evidence of current student status;
- own a GitHub personal account;
- be at least 13 years old.

GitHub may ask for an academic email. If the school does not issue one, GitHub documents alternative proof procedures.

**Do not promise that every coding-school/community student qualifies.** GitHub specifically notes that coding-school or bootcamp students may depend on their school participating in GitHub's education programs.

## Apply

1. Sign in to the student's own GitHub account.
2. Open:
   https://github.com/settings/education/benefits
3. Under GitHub Education, choose **Start an application**.
4. Follow GitHub's instructions for school/academic information and proof.
5. Submit.
6. Wait for GitHub's decision.

Possible proof may include a current school ID, class schedule, transcript, or enrollment/affiliation letter.

## Do not block setup while waiting

The student can continue with:

- GitHub Free;
- Git;
- GitHub CLI;
- VS Code;
- Copilot Free;
- Kakkoi School projects.

Education verification is an upgrade path, not a prerequisite for learning.

## Activate Copilot Student after approval

Education approval and Copilot activation are separate.

1. Open:
   https://github.com/settings/education/benefits
2. Find the student developer resources.
3. Follow the link to activate **Copilot Student**.
4. Configure the requested Copilot policies.
5. Verify the active plan in GitHub/Copilot settings.

GitHub says the student benefit may take several days to finish applying after Education approval. If only paid checkout options appear, do **not** buy a plan automatically; wait and retry or contact GitHub Support.

## Benefits change

Do not hard-code third-party Student Developer Pack offers into an AI answer without checking the current GitHub Education portal. Partner offers change.

The stable rule is:

> Verify current benefits from GitHub's Education portal at the time the student applies.
