# Create a GitHub account

## Goal

Create the student's personal GitHub identity safely.

Official guide:
https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github

## Create the account

1. Open https://github.com/signup
2. Create a personal account, or use GitHub's supported Google/Apple sign-up flow if preferred.
3. Choose a username the student is comfortable using publicly.
4. Verify the email address.

GitHub requires a verified email for some basic actions such as creating repositories.

## Choose GitHub Free

For normal student work, **GitHub Free is enough**. GitHub Free supports public and private repositories.

Do not tell a beginner they need GitHub Pro just to create repositories, clone code, use GitHub Pages for normal public projects, or collaborate on basic projects.

## Security

After the account works:

1. enable two-factor authentication;
2. save recovery codes somewhere safe;
3. consider adding a passkey.

Never ask a student to paste a password, 2FA code, recovery code, cookie, private key, or GitHub token into an AI chat.

## KakkoiSchool is separate

A personal account does not automatically give permission to create repositories inside the `KakkoiSchool` organization.

If a student needs `KakkoiSchool/PROJECT`, follow:
[../recipes/kakkoischool-repository.md](../recipes/kakkoischool-repository.md)

Do not silently create `STUDENT/PROJECT` as a substitute.
