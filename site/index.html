AI Handbook

Build a project with AI

The AI Handbook is a guide your coding assistant can read while helping you build something. It has step-by-step instructions for setting up your computer, trying a project on your own computer, and publishing it online.

How to use it

  1. Open a coding assistant such as GitHub Copilot.
  2. Paste the prompt below and describe what you want to make or fix.
  3. Try the result and tell the assistant what you want to do next. It reads the handbook instructions for the task at hand.

Read https://github.com/KakkoiSchool/ai-handbook and help me make a simple browser game.

If you’re still deciding what to make, ask for AI Guild mode. The assistant can help you compare options and choose a first step.

AIと一緒に作ってみよう

AI Handbookは、ものづくりを手伝うコーディングAI向けのガイドです。パソコンの準備から、作ったものを手元で試し、インターネットで公開するところまで、手順がまとまっています。

使い方

  1. GitHub CopilotなどのコーディングAIを開きます。
  2. 下の例文を貼り付け、作りたいものや直したいことを伝えます。
  3. できたものを試して、次にやりたいことを伝えます。AIはその作業に必要な手順をハンドブックで確認します。

https://github.com/KakkoiSchool/ai-handbook を読んで、簡単なブラウザゲームを作るのを手伝ってください。

何を作るか迷ったら、「AI Guildモードで手伝って」と伝えてください。AIと一緒に選択肢を比べ、最初に何をするか決められます。
