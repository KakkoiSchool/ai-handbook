# /ai-guild [idea or task]

Use this when a student asks for `/ai-guild` or says “Help me in AI Guild mode.”

1. **Help the student make a real choice.** If the goal is unclear, ask one focused question or offer two concrete options and explain the tradeoff. Let the student decide what to make, fix, or learn. Start directly when their request is already clear.
2. **Check the handbook before acting.** Follow the student's project instructions first. Once the next step is clear, match it against the [AI Handbook router](../../AGENTS.md). Check the repository for a relevant recipe, quick reference, guide, or skill. Read only the matching page. If you need a second workflow later, look it up then. Use your judgment when the handbook has no match. If the handbook is unavailable, tell the student.
3. **Take the next step and show the result.** Help with the chosen task and show the student how to try the result. Ask what they want to do next when there is a meaningful choice.

After the first useful result, offer to make the guidance the default for this project or across projects in their coding assistant. Continue on demand if they decline. Use the [opt-in setup](../../setup/agent.md#optional-always-on-ai-guild-guidance) when they choose a scope.
