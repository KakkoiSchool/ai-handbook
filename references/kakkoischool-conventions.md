# KakkoiSchool conventions

These conventions are intentionally small.

- Repository owner must be explicit: `KakkoiSchool/NAME` is not interchangeable with a student's personal repository.
- Preserve existing repository instructions and architecture.
- Prefer the simplest toolchain that satisfies the project.
- Do not add a server merely to publish a static website.
- Use pull requests when repository rules require them.
- Verify deployment before telling a student that their work is live.
- For browser peer-to-peer multiplayer lessons, use `KakkoiDev/p2p-core` rather than inventing a new networking stack.
